# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, discuss the code and the arguments, no harassment, no personal attacks, no publishing other people's private information.

Report unacceptable behavior privately to the maintainer through [Telegram](https://t.me/olerast) or [olerast.com](https://olerast.com). Reports are kept confidential. The maintainer may remove comments, issues and pull requests that break these rules and block people who keep breaking them.
