Dela хранит ваши задачи на вашем сервере зашифрованными

Dela это менеджер задач с открытым кодом. На каждом устройстве лежит полная копия задач, поэтому приложение открывается сразу и работает без сети. Задачи шифруются на устройстве ключом, которого у сервера нет. Браузер, Windows, Android и часы Wear OS, лицензия AGPL-3.0.

Попробовать без сервера Скачать

В демо задачи хранятся зашифрованными только в этом браузере. Исходный код лежит на GitHub.

Что видит сервер

Сервер хранит, упорядочивает и раздаёт зашифрованные изменения и проверяет права доступа. Шифрование включено всегда, выключить его нельзя.

Сервер знает

  • адреса почты и список устройств
  • участников общих проектов
  • время каждого изменения и его размер, округлённый до 64 байт
  • время напоминаний, если включены push-напоминания
  • размер приложенных файлов

Получает только шифротекст

  • текста задач, описаний и комментариев
  • дат, меток и названий проектов
  • названий полей и идентификаторов записей
  • приложенных файлов
  • ссылок на календари и мест для напоминаний по месту

Argon2id выводит из пароля на устройстве два ключа: один подтверждает вход на сервере, другой открывает ключ аккаунта. Каждое изменение шифруется XChaCha20-Poly1305 ключом своего проекта. Если потеряны и пароль, и ключ восстановления, данные расшифровать нельзя.

В браузере код веб-версии отдаёт ваш сервер. Расширение Dela Verify сверяет файлы, которые загрузила страница, со списком хешей, который проект подписывает к каждому выпуску, и показывает красный значок, если они расходятся. У программ для Windows и Android код свой, а их обновления подписаны. Подробности и известные ограничения: архитектура, безопасность в README, политика конфиденциальности.

Что добавилось в версиях 0.6-1.0

Статистика, утренняя сводка и распознавание картинок и голоса работают на устройстве. Точка справа показывает, где работает функция.

Открыть последний выпуск

При первом входе приложения спрашивают адрес вашего сервера.

Установить сервер

Нужен сервер с Docker и домен, DNS-запись которого указывает на этот сервер. Встроенный Caddy сам получает сертификат HTTPS.

mkdir dela && cd dela
curl -fsSLO https://raw.githubusercontent.com/olerast67/dela/main/docker-compose.yml
curl -fsSL https://raw.githubusercontent.com/olerast67/dela/main/.env.example -o .env
nano .env    # ваша почта и домен
docker compose --profile https up -d

Потом откройте https://<ваш домен> и зарегистрируйтесь с почтой из .env. Этот первый аккаунт станет администратором, остальным нужно приглашение. За своим обратным прокси запускайте без профиля: Dela слушает 127.0.0.1:8080.

Перед каждой миграцией и раз в день сервер копирует базу. Обновление: docker compose pull и тот же up -d. Все настройки описаны в README.
