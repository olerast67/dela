Dela keeps your tasks encrypted on your own server

Dela is an open-source task manager. Every device keeps a full copy of the tasks, so the app opens instantly and works without a network. Tasks are encrypted on the device with a key the server does not have. Browser, Windows, Android and Wear OS watches, under AGPL-3.0.

Try it without a server Download

The demo keeps tasks encrypted in this browser only. The source code is on GitHub.

What the server can see

The server stores, orders and hands out encrypted changes and checks access rights. Encryption is always on and cannot be turned off.

The server knows

  • email addresses and the list of devices
  • members of shared projects
  • when a change was made and its size, rounded to 64 bytes
  • reminder times, if push reminders are on
  • the size of attached files

It gets only ciphertext of

  • task text, descriptions and comments
  • dates, labels and project names
  • field names and record IDs
  • attached files
  • calendar links and the places of location reminders

Argon2id derives two keys from the password on the device: one proves the login to the server, the other unlocks the account key. Every change is encrypted with XChaCha20-Poly1305 using the key of its project. If both the password and the recovery key are lost, the data cannot be decrypted.

In a browser, the web app code comes from your server. The Dela Verify extension compares the files the page loaded with a list of hashes that the project signs for every release, and shows a red badge when they differ. The Windows and Android apps carry their own code, and their updates are signed. Details and known limitations: architecture, security in the README, privacy policy.

Download the apps

All files are on the page of the latest release. GitHub Actions builds them from the version tag, and every file has a build provenance attestation that gh attestation verify checks.

  • Windows 10 and 11Dela_<version>_x64-setup.exeInstalls for the current user. The installer is not code-signed yet, so SmartScreen asks for confirmation. Later versions install themselves from the app.
  • Android 7 and newerDela-<version>-android.apkUpdates through Obtainium.
  • Wear OS 3 and newerDela-<version>-wear.apkA separate watch app. It signs in with your email and password and shows up as its own device in the device list in Settings.
  • Any browseryour server addressInstalls as an app on a computer and on Android. On an iPhone, open it in Safari and add it to the home screen; push reminders work from iOS 16.4.
  • Dela VerifyDela-Verify-<version>.zipBrowser extension for Chrome, Edge and Firefox that checks the web app of your server against the signed release.
  • AI assistantsnpx dela-mcp loginMCP server for Claude Desktop and other MCP clients. Setup is in the dela-mcp README.

Install the server

You need a server with Docker and a domain name whose DNS record points to it. The bundled Caddy gets the HTTPS certificate itself.

mkdir dela && cd dela
curl -fsSLO https://raw.githubusercontent.com/olerast67/dela/main/docker-compose.yml
curl -fsSL https://raw.githubusercontent.com/olerast67/dela/main/.env.example -o .env
nano .env    # your email and domain
docker compose --profile https up -d

Then open https://<your domain> and register with the email from .env. That first account becomes the administrator, and everyone else needs an invite. Behind your own reverse proxy, start without the profile: Dela listens on 127.0.0.1:8080.

The server copies the database before every migration and once a day. Updating is docker compose pull and the same up -d. All settings are in the README.

Dela and Todoist

I built Dela as a self-hosted replacement for Todoist. It understands Todoist filters and imports your projects by API token or from an export file.
