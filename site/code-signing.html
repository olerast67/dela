Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Windows installer Dela_<version>_x64-setup.exe. It is built by the GitHub Actions workflow release.yml from the tagged source of the public repository olerast67/dela, with no files added outside the build. Every release file also has a build provenance attestation that can be checked with gh attestation verify.

Dela is licensed under AGPL-3.0. All components are open source.

Team roles

Committers and reviewers: olerast67.

Approvers: olerast67. Each signing request is started by a release workflow run on a version tag and approved by the approver.

Contributions from other people go through pull requests reviewed by the committer, see CONTRIBUTING.md.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The Windows app connects to the Dela server whose address the user enters, and checks GitHub for a newer release of the app at startup. Task contents are encrypted on the device before they reach the server. Details are in the privacy policy.
