# Dela

[English](README.md)

Открытый менеджер задач Dela работает в браузере и ставится на свой сервер одним контейнером Docker. Задачи шифруются на устройстве ключом, которого у сервера нет, и доступны без сети.

## Состояние проекта

Версия 0.1.0, ранняя разработка. Сейчас есть веб-приложение, которое устанавливается как PWA на компьютер и телефон. Нативных приложений для Windows, macOS, Linux, Android и iOS пока нет, план в [ROADMAP.md](ROADMAP.md).

Код проекта пишет Claude от Anthropic по моим задачам. Каждый шаг проверяется модульными тестами и сквозными тестами в Chromium, которые запускаются в GitHub Actions на каждый коммит.

## Возможности

- Быстрый ввод разбирает фразы на русском и английском. Строка «позвонить маме завтра в 19 №Дом каждую неделю !1» становится задачей со сроком, проектом, повтором и приоритетом. Распознанные части подсвечиваются, и любую из них можно оставить в названии.
- Задачи группируются по проектам, разделам и подзадачам. У задачи есть метки, приоритет, срок со временем и часовым поясом, дата начала, дедлайн и длительность.
- Повторы задаются по расписанию или от даты выполнения, например «каждый второй вторник месяца» или «каждые 3 дня после выполнения».
- Есть экраны «Сегодня» и «Предстоящие», проект можно смотреть списком или доской.
- Фильтры записываются в синтаксисе Todoist (`(today | overdue) & p1`, `#Работа & !@ждёт`) или русскими словами (`сегодня | просрочено`).
- Напоминания приходят в открытом приложении и через Web Push, когда приложение закрыто.
- Проект можно сделать общим и пригласить участников по адресу почты.
- Импорт из Todoist работает по токену API или из файла выгрузки. Экспорт сохраняет данные в JSON и Markdown.
- Командная палитра открывается по `Ctrl+K`. Горячие клавиши работают и в русской раскладке, задачи перетаскиваются мышью. `Ctrl+Z` отменяет действия, история хранит 100 последних.

## Установка

Нужен сервер с Docker и доменное имя. Service worker и Web Push работают только по HTTPS, поэтому перед Dela ставится обратный прокси.

```bash
curl -O https://raw.githubusercontent.com/olerast67/dela/main/docker-compose.yml
docker compose up -d
```

Контейнер слушает порт 8080 на `127.0.0.1`. Пример настройки Caddy, который сам получит сертификат:

```
tasks.example.com {
	reverse_proxy 127.0.0.1:8080
}
```

Первый зарегистрированный пользователь становится администратором. После него регистрация закрыта: администратор создаёт приглашение в «Настройки → Приглашения» и отправляет ссылку. Открыть регистрацию для всех можно переменной `DELA_OPEN_REGISTRATION=true`.

## Настройки

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `DELA_PORT` | `8080` | Порт сервера |
| `DELA_HOST` | `0.0.0.0` | Адрес, на котором слушает сервер |
| `DELA_DATA_DIR` | `/data` в образе | Папка с базой и резервными копиями |
| `DELA_OPEN_REGISTRATION` | `false` | Регистрация без приглашения |
| `DELA_BACKUP_KEEP` | `7` | Сколько ежедневных снимков базы хранить, `0` отключает снимки |
| `DELA_SESSION_TTL_DAYS` | `180` | Срок жизни сессии устройства в днях |
| `DELA_MAX_CLOCK_DRIFT_MS` | `60000` | На сколько миллисекунд часы устройства могут спешить относительно сервера |
| `DELA_VAPID_SUBJECT` | адрес репозитория | Контакт для push-сервисов, `mailto:` или `https:` |

## Обновление

```bash
docker compose pull
docker compose up -d
```

Миграции базы применяются при запуске. Перед миграцией сервер сохраняет копию базы в `/data/dela.sqlite.before-vN-<время>.bak`.

## Резервные копии

Раз в сутки сервер сохраняет снимок базы в `/data/backups/dela-ГГГГ-ММ-ДД.sqlite` и хранит последние семь. Задачи в снимке зашифрованы, и восстановить их можно только с паролем или ключом восстановления владельца. Полную выгрузку в открытом виде делает само приложение в «Настройки → Экспорт».

## Безопасность

Пароль не уходит на сервер. Из него на устройстве Argon2id выводит два ключа: один подтверждает вход, второй открывает мастер-ключ аккаунта. Каждое изменение шифруется XChaCha20-Poly1305 ключом пространства (libsodium).

Сервер видит адрес почты, список устройств, участников общих проектов, время изменений, размер каждого изменения с точностью до 64 байт и время отправки напоминаний. Текст задач, даты, метки, названия проектов, названия полей и идентификаторы записей хранятся у сервера только в зашифрованном виде.

При регистрации приложение показывает ключ восстановления. Если потерять и пароль, и этот ключ, данные расшифровать нельзя.

Ограничения сейчас такие:

- В браузере данные лежат в IndexedDB в расшифрованном виде. Ключи аккаунта зашифрованы ключом WebCrypto, который нельзя извлечь из браузера.
- Участник, которого убрали из общего проекта, теряет доступ к серверу, но ключ проекта, полученный раньше, у него остаётся. Смена ключа после исключения запланирована.
- Двухфакторной защиты входа (TOTP) и блокировки приложения PIN-кодом пока нет.

Подробное описание протокола и ключей лежит в [docs/architecture.md](docs/architecture.md). Об уязвимостях сообщайте через приватный отчёт на GitHub (Security → Report a vulnerability).

## Разработка

Нужен Node.js 22.18 или новее.

```bash
npm install
npm run check        # типы и модульные тесты
npm run test:e2e     # сборка веб-клиента и сценарии в Chromium (Playwright)
npm run build:web
npm start            # сервер на http://localhost:8080 вместе с веб-клиентом
```

Репозиторий устроен так:

| Папка | Что в ней |
|---|---|
| `packages/core` | Ядро для всех платформ: синхронизация, шифрование, модель задач, разбор фраз, повторы, фильтры |
| `apps/server` | Сервер на Node.js, Hono и встроенной SQLite |
| `apps/web` | Веб-клиент на React и Vite |
| `e2e` | Сквозные тесты Playwright |
