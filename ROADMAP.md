# План разработки Dela

Отметка `[x]` ставится, когда шаг прошёл свою проверку (тесты или ручной сценарий из описания шага).
Решения по архитектуре: [docs/architecture.md](docs/architecture.md). Визуальная основа: [docs/design.md](docs/design.md).

## Фаза 0. Скелет (ядро, сервер, веб-список)

Критерий фазы: два браузера с правками офлайн сходятся к одному состоянию; ночная симуляция без расхождений.

- [x] 0.1 Репозиторий: TypeScript strict, Vitest, документы, лицензия
- [x] 0.2 Ядро: UUIDv7, гибридные часы (HLC), дробные ключи порядка, слияние по полям (LWW), эталонный ретранслятор, симуляция N устройств
- [x] 0.3 Ядро: шифрование (libsodium): ключи аккаунта и пространств, конверт операции, слоты HMAC, выравнивание размера
- [x] 0.4 Сервер: регистрация и вход без передачи пароля, устройства, пространства, отправка и получение операций, сигнал «есть новое» по WebSocket, SQLite
- [x] 0.5 Ядро: модель задач (проекты, разделы, задачи, метки), дерево без циклов, мягкое удаление
- [x] 0.6 Ядро: разбор фраз RU и EN (даты, время, `#`/`№`, `@`, `p1`/`!1`), корпус тестов
- [x] 0.7 Ядро: повторы (RRULE, режим «от выполнения»), выполнение без дублей
- [x] 0.8 Веб: React + Vite, IndexedDB, PWA, вход с шифрованием, Входящие, Сегодня, Предстоящие, проекты, метки, поиск, быстрый ввод, панель задачи, отмена
- [x] 0.9 Сквозной тест: два браузера, офлайн, сходимость (Playwright)

## Фаза 3. Хвосты и доверие

Критерий: в Dela не осталось известных недоделок 0.5.0, выпуски собирает GitHub Actions, и любой может проверить, что APK и установщик собраны из открытого кода.

Хвосты 0.5.0:
- [x] 3.1 Время по формату языка: в английском интерфейсе «7:00 PM», в русском «19:00». Везде, где показывается время: списки, карточка, календарь, виджет, уведомления
- [x] 3.2 Виджет Android на языке приложения: язык уходит в снимок задач вместе со списком, виджет и экран его настроек берут строки по нему
- [x] 3.3 Превью виджета в списке виджетов лаунчера: `previewLayout` со списком задач для Android 12 и новее, картинка `previewImage` для старых версий
- [x] 3.4 Проверка на телефоне: плитка быстрого добавления в шторке и доставка напоминаний через ntfy при закрытом приложении. Проверено на Samsung S24 FE 20.10.2026: плитка открывает быстрое добавление, напоминание задачи с телефона приходит при закрытом приложении. Нашлась и исправлена ошибка: задача, добавленная на другом устройстве, на телефон не напоминала
- [ ] 3.5 Подпись установщика для Windows через SignPath Foundation: страница с правилами подписи (code signing policy) на сайте проекта, заявка автора, секреты в GitHub. Сборка и подпись в Actions готовы, страница site/code-signing.html опубликована. Осталась заявка автора (текст в docs/code-signing.md)
- [x] 3.6 Сборка выпусков в GitHub Actions: APK и установщик собираются из тега, к выпуску прикладывается заверенное происхождение сборки (`gh attestation verify`), как у Суфлёра. Ключи в окружении `release`, так вышли 0.6.0 и 0.7.0
- [x] 3.7 `@hono/node-server` 2.x: перейти, когда выйдет совместимый `@hono/node-ws`, или заменить `@hono/node-ws` на библиотеку `ws` напрямую и снять правило в dependabot.yml

Доверие:
- [x] 3.8 Защита от подмены веб-версии. Проверка внутри страницы не защищает: её код отдаёт тот же сервер. Шаги: в README и на экране входа в браузере совет пользоваться приложениями для Windows и Android, у них код свой; к каждому выпуску список хешей файлов веб-клиента, подписанный ключом проекта; расширение для браузера (Chrome и Firefox), которое сверяет загруженные файлы с этим списком и предупреждает о несовпадении
- [x] 3.9 Подписанные комментарии в общих проектах: у каждого пользователя ключ подписи Ed25519, комментарий подписывается при создании, интерфейс показывает «подпись не сходится» вместо имени автора. Подпись правок задач обсудить отдельно: это 64 байта на каждую операцию
- [x] 3.10 Ключ восстановления плюс код двухфакторного входа: настройка для тех, у кого включён TOTP. По умолчанию выключена, иначе потеря телефона с аутентификатором закрыла бы аккаунт навсегда

- [ ] 4.6 Raspberry Pi: проверить образ arm64 на настоящей плате и описать в README

## Фаза 5. Функции

Критерий: автор месяц пользуется Dela вместо Todoist и Obsidian, и ни одна функция из этого этапа не требует от автора отдельного сервера.

Задачи и напоминания:
- [x] 5.1 Напоминания фразой: «напомни за час», «напомни в 9 утра», «напоминать каждый день в 20:00» в быстром добавлении на русском и английском
- [ ] 5.2 Статистика выполненных задач по дням и неделям, считается на устройстве. Сервер о ней ничего не узнаёт
- [ ] 5.3 Вложения больше 7 МБ: загрузка по частям, каждая часть шифруется отдельно, предел на файл задаётся в настройках сервера
- [ ] 5.4 Привычки: задача-привычка с серией дней подряд и лучшей серией, пропуск дня без потери серии по правилу привычки
- [ ] 5.5 Таймер помодоро на задаче: 25 и 5 минут по умолчанию, учёт затраченного времени в задаче, уведомление по окончании
- [ ] 5.6 События календарей поверх задач в «Сегодня» и в календаре, только для чтения. На Android календари телефона через `CalendarContract` (разрешение `READ_CALENDAR`), на Windows и в браузере подписка на ссылку iCal (например, секретная ссылка Google Calendar). Ссылки хранятся зашифрованными в личном пространстве. В браузере подписка работает, только если календарь разрешает запросы с других сайтов (CORS), иначе через приложения
- [ ] 5.7 Сервер MCP для ИИ-ассистентов: программа на компьютере пользователя (`npx dela-mcp`), входит на его сервер Dela, держит ключи у себя и даёт Claude Desktop и другим клиентам MCP инструменты: найти, добавить, изменить, выполнить задачу. Отдельный сервер от автора не нужен
- [ ] 5.8 Задача из картинки и голосового сообщения через «Поделиться» на Android. Текст с картинки распознаёт Tesseract на устройстве, голос распознаёт sherpa-onnx, как в Суфлёре. Модели распознавания речи весят десятки мегабайт, поэтому они скачиваются отдельно по желанию пользователя, и APK не растёт
- [ ] 5.9 Напоминание по месту на Android: зоны через `LocationManager` без сервисов Google, разрешение на геолокацию в фоне спрашивается только при первом таком напоминании. Координаты хранятся зашифрованными
- [ ] 5.10 Часы на Wear OS: отдельное приложение для часов со списком «Сегодня», отметкой «выполнено» и напоминаниями. Связь телефона с часами через Wearable Data Layer требует сервисов Google, поэтому часы ходят на сервер Dela сами, со своим входом и ключами

Из обновлений Todoist (сверка 20.10.2026 со страницей product-updates; командные функции, облачный ИИ и двусторонняя синхронизация с Google и Outlook не взяты, у них сервер или чужой сервис видит текст задач):
- [x] 5.11 Выделение нескольких задач и действия над всеми сразу: выполнить, перенести в проект, поставить дату, приоритет и метку, удалить. На телефоне выделение долгим нажатием
- [x] 5.12 Несколько задач одним вводом: вставленный в быстрое добавление список разбивается по строкам, каждая строка разбирается как фраза (дата, проект, метка, приоритет)
- [x] 5.13 Экран при запуске: «Сегодня», «Входящие», проект или фильтр по выбору в настройках
- [x] 5.14 Группировка и сортировка в списках: по дате, приоритету, проекту и метке. «Сегодня» доской по приоритетам
- [x] 5.15 Календарь: режим «3 дня», цвет задач по проекту или приоритету, боковая панель с просроченными задачами и задачами без даты для перетаскивания на сетку, скрытие будущих повторов
- [x] 5.16 Повтор кнопками: дни недели, интервал, день месяца, дата окончания. Текстовое поле повтора остаётся
- [x] 5.17 Утренняя сводка: уведомление в выбранное время с числом задач на сегодня и просроченных, считается на устройстве
- [ ] 5.18 Срочное напоминание на Android: полноэкранный будильник поверх беззвучного режима и «Не беспокоить», включается у отдельной задачи
- [x] 5.19 Markdown в описании и комментариях: списки, ссылки, чек-листы, таблицы. HTML только через санитайзер
- [x] 5.20 Подзадачи раскрываются в «Сегодня», «Предстоящих» и фильтрах. Выполненный сегодня повтор виден в «Сегодня» отмеченным
- [x] 5.21 Описание у проекта и раздела
- [ ] 5.22 Программа для Windows: запуск при входе в систему, проект или задача в отдельном окне
- [ ] 5.23 Ссылка на текущий экран или задачу (Ctrl+Shift+C), открывается в приложении на любом устройстве аккаунта

## Отложено

- iOS, iPadOS и Apple Watch: для сборки и отладки нужен Mac. Сейчас на iPhone работает веб-версия в Safari: «Поделиться → На экран „Домой“», напоминания через Web Push начиная с iOS 16.4. Сборку можно вести на macOS в GitHub Actions, но для выпуска нужна учётная запись Apple Developer и iPhone для проверки
- Серверный помощник с выданным ключом: Telegram-бот, письмо в задачу, REST API
- ИИ по согласию: разбивка задачи на шаги, план дня
- Облако проекта (платная подписка, тот же код), push через FCM и APNs для сборок из Google Play и App Store
- Внешний аудит криптографии и протокола
- Пространства для семьи и команды, CalDAV через помощника
- Публичный проект только для чтения: ссылка с ключом после `#`, сервер видит шифротекст. Нужен разбор, что делать при отзыве ссылки
